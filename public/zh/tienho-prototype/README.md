# 天河村：梦与现实

主线中的天河村章节，以全屏页面嵌入游戏。

## 试玩

```bash
cd /Users/ningzhou/Documents/Codex/2026-08-17/hi
npm run dev
```

从主线进入天河村，或使用项目提供的天河村预览入口。

## 当前体验范围

1. 喝茶入梦，不标注“梦境”。
2. 拖动金币给寡妇、点击粮袋分米、点亮三盏灯笼。
3. 称呼依次从“陌生人”变成“带着无数黄金的陌生人”，围观者同步增加。
4. 庆典鼓点逐渐变为撞门声，梦境底图原地交叉淡化成主线夜景。
5. “再给一些！”保持不变，花瓣变成金币。
6. 玩家按住钱袋，触发第一次强夺。
7. 从介绍信、十字架、金币和萨托翻译中选择一种身份凭证；界面展示“本意—他人所见—新传闻”的因果链。
8. 身份自证必然失败，但四种选择以不同方式推高门外压力。
9. 逃亡时按住钱袋可以保住金币，却会降低速度并让人群逼近；松开后金币沿途洒落，出口进度加快。
10. 抵达后窗后，必须主动割断钱袋才能逃生。
11. 割断钱袋后不显示总结页，直接进入荒野。
12. 荒野不再显示左侧步骤表，只保留放大的圆形动作按钮；每次行动都会触发一次短促的黑屏与复明。动作依次退化为“向前走”“站稳”“抬起脚”“呼吸”，最后通过按住完成“保持清醒”“呼吸”“不要睡去”，随后画面永久转黑。
13. 彻底黑屏后自动进入修道院章节；嵌入主线时会直接触发三次钟声与睁眼序列。

交互音效由 Web Audio 即时生成，模拟瓷杯、铜钱、米粒与木斗、纸张、灯笼竹骨、皮革、皮面手鼓和断裂的皮绳，不使用升调提示音或电子界面音。背景音乐使用双播放器交叉淡化：梦境为幽微圆舞曲，惊醒、盘问与逃亡转入追逼乐，荒野改为低沉幽灵音色，昏倒时音乐完全消失，随后自动进入修道院沉思曲。声音开关同时控制交互音效与配乐。

开发预览可用 `?stage=identity`、`?stage=escape` 或 `?stage=wilderness` 直接进入对应阶段。

## 资产说明

- `assets/tienho-reality.webp`：天河村的现实夜景。
- `assets/tienho-dream.webp`：使用内置 imagegen 依据夜景同机位生成的梦境对应图。
- `assets/teodoro-run.webp`：逃亡阶段的特奥多罗透明人物资产。
- `assets/wilderness-teodoro-v2.webp`：重绘后的荒野场景，前景人物与前段特奥多罗的面貌和十九世纪黑色礼服保持一致。
- `assets/mission-cloister.webp`：独立预览模式下用于验证修道院衔接；嵌入主线时由主线播放钟声与睁眼序列。
